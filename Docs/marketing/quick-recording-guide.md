# 아이폰에서 물 마시기 기록을 쉽게: 위젯·애플워치·단축어 설정법

> 발행 전 초안입니다. App Store 설치본의 동작과 처음 사용하는 사람의 따라 하기는 아직 확인하지 않았습니다. [실행 기록](../exec-plans/active/2026-09-25-issue-329-quick-recording-guide.md)에서 검증을 마친 경로만 공개합니다.

물을 마신 뒤 기록할 때, 자주 쓰는 화면에서 바로 시작해 보세요. 물리미는 홈 화면 위젯, Apple Watch 앱, Siri·단축어로 물을 기록할 수 있습니다. 내 생활에 맞는 방법 하나부터 설정하면 됩니다.

## 내게 맞는 방법 고르기

| 이런 때 쓰고 싶어요 | 방법 | 필요한 기기·OS | 기록 방법 |
| --- | --- | --- | --- |
| 책상에서 iPhone을 보다가 기록하고 싶어요 | [홈 화면 위젯](#홈-화면-위젯으로-기록하기) | iOS 26 이상 iPhone | 위젯의 `마시기` 버튼으로 기본 한 잔 기록 |
| 이동 중 손목에서 기록하고 싶어요 | [Apple Watch](#apple-watch에서-기록하기) | iOS 26 이상 iPhone과 페어링된 watchOS 26 이상 Apple Watch | Watch의 물리미 앱에서 기본 한 잔 기록 |
| 손이 바쁠 때 말하거나 기록량을 골라 입력하고 싶어요 | [Siri·단축어](#siri단축어로-기록하기) | iOS 26 이상 iPhone, 단축어 앱 / 음성 실행에는 Siri 설정 | 기본 한 잔 또는 단축어에서 선택한 양 기록 |

위젯과 Watch의 기본 한 잔은 250ml입니다. 다른 양을 기록하려면 단축어의 수분량 선택을 이용하세요. 실제로 마신 양에 맞게 기록하면 됩니다.

## 처음 한 번 준비하기

1. App Store에서 물리미를 검색해 설치하고 앱을 엽니다.
2. 로그인과 처음 사용 안내를 마치고 하루 목표량을 설정합니다.
3. 건강 앱 연동 안내에서 **수분 기록의 쓰기와 읽기 권한**을 확인합니다. 쓰기는 기록 저장, 읽기는 저장한 기록과 오늘 합계 확인에 필요합니다.
4. 아래에서 방법 하나를 선택합니다. 실제로 물을 마신 뒤 한 번 실행하고, [저장 결과 확인](#기록이-저장됐는지-확인하기)까지 따라 해보세요.

건강 권한을 다시 확인하려면 iPhone의 건강 앱에서 프로필 → 개인정보 보호의 앱 → 물리미로 이동해 수분 항목을 확인합니다. 메뉴 이름은 OS에 따라 다를 수 있습니다. [Apple의 건강 데이터 관리 안내](https://support.apple.com/ko-kr/108779)

## 홈 화면 위젯으로 기록하기

**필요한 것:** iOS 26 이상 iPhone, 물리미 설치와 위의 초기 설정.

1. iPhone 홈 화면의 빈 곳을 길게 누릅니다.
2. `편집` → `위젯 추가`를 누르고 물리미를 찾습니다.
3. 물리미의 `물 마시기` 작은 위젯을 추가하고 `완료`를 누릅니다. [Apple의 위젯 추가 안내](https://support.apple.com/ko-kr/118610)
4. 물을 마신 뒤 위젯의 `마시기` 버튼을 한 번 누릅니다. 기본 한 잔을 기록합니다.
5. [저장 결과](#기록이-저장됐는지-확인하기)를 확인합니다. 위젯 숫자가 바로 바뀌지 않으면 앱과 건강 앱의 기록부터 확인하세요.

물리미의 일반 **잠금 화면 위젯은 오늘 섭취량을 확인하는 용도**입니다. 이 절차에서 추가하는 것은 기록 버튼이 있는 홈 화면 위젯입니다.

## Apple Watch에서 기록하기

**필요한 것:** iOS 26 이상 iPhone과 페어링된 watchOS 26 이상 Apple Watch, 물리미 초기 설정과 건강 권한.

1. iPhone의 `Watch` 앱에서 `나의 시계`를 엽니다.
2. 물리미가 설치되어 있는지 확인합니다. `사용 가능한 앱`에 있다면 물리미 옆의 `설치`를 누릅니다. [Apple의 Watch 앱 설치 안내](https://support.apple.com/ko-kr/109023)
3. Apple Watch에서 물리미 앱을 엽니다.
4. 물을 마신 뒤 기록 버튼을 한 번 누릅니다. 기본 한 잔을 기록합니다.
5. Watch 화면의 오늘 기록을 확인하고, iPhone에서도 [저장 결과](#기록이-저장됐는지-확인하기)를 확인합니다.

건강 권한 오류가 나오면 iPhone 건강 앱의 물리미 권한을 확인하세요. iPhone에서 허용했다는 이유만으로 Watch 기록 성공을 가정하지 말고 실제 저장 결과를 확인합니다. Watch와 iPhone의 표시가 다르면 연결 상태와 동기화를 확인하고, 같은 물을 다시 기록하기 전에 기존 기록부터 살펴보세요.

## Siri·단축어로 기록하기

**필요한 것:** iOS 26 이상 iPhone, 단축어 앱, 물리미 초기 설정과 건강 권한. 음성으로 실행하려면 iPhone에서 Siri를 사용할 수 있어야 합니다.

### 단축어 앱에서 실행

1. iPhone의 단축어 앱을 열고 왼쪽 위의 뒤로 가기 버튼으로 단축어 목록을 엽니다. `앱 단축어` 영역에서 물리미를 찾습니다.
2. 물리미의 `물 기록`을 누르면 기본 한 잔 기록을 실행합니다. 결과 안내를 확인한 뒤 [실제 저장 여부](#기록이-저장됐는지-확인하기)를 확인합니다.

다른 양을 기록하려면 실행 전에 단축어를 편집하세요.

1. 물리미의 `물 기록` 옆 더보기 메뉴에서 `새로운 단축어에서 사용`을 선택합니다. [Apple의 앱 단축어 안내](https://support.apple.com/ko-kr/guide/shortcuts/apd43295406d/ios)
2. 편집기에 추가된 `물 마시기 기록` 동작에서 `수분량`을 선택합니다. 250ml·330ml·500ml·직접 입력 중 하나를 고를 수 있습니다.
3. `직접 입력`을 골랐다면 `직접 입력 ml`에 실제 마신 양을 넣습니다. 1~4000ml 범위로 입력할 수 있습니다.
4. 단축어 이름을 정해 저장한 뒤 실행합니다. 결과 안내와 [실제 저장 여부](#기록이-저장됐는지-확인하기)를 확인합니다.

수분량 선택은 그 단축어 실행에 적용됩니다. 홈 화면 위젯과 Watch의 기본 한 잔 기록량은 바뀌지 않습니다.

### Siri에게 말하기

1. iPhone에서 Siri를 부릅니다.
2. **“물리미에서 물 기록”**이라고 말합니다.
3. 권한 확인이나 잠금 해제를 요청하면 안내를 따릅니다. 저장되지 않았다는 안내가 나오면 원인을 확인한 뒤 다시 실행합니다.
4. [저장 결과](#기록이-저장됐는지-확인하기)를 확인합니다.

앱을 열어야 하는 단축어는 잠긴 기기에서 잠금 해제를 요청할 수 있습니다. [Apple의 Siri 단축어 실행 안내](https://support.apple.com/ko-kr/guide/shortcuts/apd07c25bb38/ios)

## 기록이 저장됐는지 확인하기

1. 물리미를 열어 오늘 기록에 방금 입력한 양이 추가됐는지 확인합니다.
2. 건강 앱에서 `수분` 항목의 `모든 데이터 보기`를 열어 새 기록의 시각·양·출처를 확인합니다. 물리미에서 방금 남긴 기록인지 확인하세요.

위젯 표시 갱신이나 Watch 동기화에는 시간이 걸릴 수 있습니다. 버튼을 눌렀거나 완료 안내를 봤어도 기록이 확인되지 않으면, 같은 양을 반복해서 입력하기 전에 건강 앱부터 확인하세요.

## 설정하거나 기록하다 막혔다면

| 상황 | 확인할 내용 |
| --- | --- |
| 위젯이나 물리미 단축어를 찾을 수 없어요 | 물리미를 한 번 열어 초기 설정을 마쳤는지, 설치한 버전이 해당 기능을 지원하는지 확인하세요. |
| 건강 권한이 필요하다고 나와요 | 건강 앱 → 프로필 → 앱 → 물리미에서 수분 권한을 확인한 뒤 물리미로 돌아오세요. 권한 확인만으로 새 기록이 저장되지는 않습니다. |
| 목표를 달성했거나 이번 기록량이 목표를 넘어요 | 현재 목표를 초과하는 양은 기록되지 않습니다. 오늘 합계와 실제 마신 양에 맞는 기록량을 확인하세요. |
| 저장 실패 안내가 나와요 | 건강 앱에 기록이 생겼는지 먼저 확인하고, 권한이나 오류 원인을 확인한 뒤 다시 시도하세요. |
| Watch 기록이 iPhone에서 아직 안 보여요 | Watch의 기록과 기기 연결 상태를 확인하고 동기화를 기다리세요. 확인 전 같은 양을 중복 입력하지 마세요. |

가이드대로 설정한 뒤 오늘 첫 잔을 기록해 보세요.
