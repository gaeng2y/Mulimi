# Profile Information Architecture

## Goal
`Profile` 탭을 개인 관리 허브로 사용하고, `Settings` 화면은 세부 설정 허브로 역할을 분리한다.

## Profile Root
- 루틴: 루틴 관리 화면으로 진입
- 목표 추천: AI 목표 추천 진입 카드. 문구는 목표 부족/초과, 신체 정보/권한, 모델 사용 가능 상태를 반영하고, 신체 정보가 필요하면 `신체 정보` 화면으로, 그 외에는 `하루 목표량` 화면으로 연결한다
- 빠른 설정: `하루 목표량`, `메인 아이콘`을 바로 수정
- 계정: `회원 탈퇴` 진입
- 앱 정보: 버전과 빌드 번호 확인
- 현재 설정: 자주 확인하는 개인화 값 요약

## Goal Recommendation Entry Rules
- 추천 실행과 결과 카드는 `하루 목표량` 상세(`DailyLimitSettingView`)의 기존 추천 카드가 담당한다. Profile root 카드는 진입점 역할만 한다
- 모델을 사용할 수 없는 환경에서는 fallback 문구로 직접 조정을 안내하고 `하루 목표량` 화면으로 연결한다
- 목표 부족/초과 판단은 주간 평균 대비 목표 비율(0.7 미만 부족, 1.15 초과 초과)을 쓰고, 기록이 없거나 경과일이 3일 미만이면 판단하지 않는다

## Settings Screen
- 개인화: `하루 목표량`, `메인 아이콘`
- 계정 관리: `회원 탈퇴`

## Role Separation
- `Profile`은 자주 접근하는 개인 관리 액션과 정보 요약을 제공한다.
- `Settings`는 전체 설정을 모아두는 세부 설정 허브 역할을 유지한다.
