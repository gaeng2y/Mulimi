# Mulimi 동작 검증

저장소 전용 진입점이다. [AGENTS.md](../../../AGENTS.md)를 먼저 따르고 다음 문서의 실제 절차를 수행한다.

- [검증 증거와 상태](../../../Docs/quality-gates.md#검증-증거): 주장에 맞는 근거와 미검증 범위.
- [버그 재현과 수정 검증](../../../Docs/quality-gates.md#버그-재현과-수정-검증): 수정 전 재현부터 같은 경로의 수정 후 확인까지.
- [시뮬레이터 실행·캡처](../../../Docs/skills/xcode-build-test.md#시뮬레이터-버그-검증): 담당 인스턴스와 실제 실행 빌드 확인.
- [변경 유형별 검사](../../../Docs/quality-gates.md#validation-matrix): 관련 테스트·빌드 선택.

결과에는 확인한 동작, 수정 전후 증거 경로, 실행 결과와 남은 미검증을 적는다. 검증만 요청받았다면 결함을 임의로 수정하지 않는다. 기능별 UI 자동화 도구나 테스트를 제공하는 스킬은 아니므로 사용할 조작 경로는 현재 앱과 도구에서 확인한다.
