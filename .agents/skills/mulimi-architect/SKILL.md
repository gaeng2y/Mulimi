# Mulimi 구현 전 설계

[AGENTS.md](../../../AGENTS.md)와 [ARCHITECTURE.md](../../../ARCHITECTURE.md)를 먼저 따르고 [구현 전 설계 절차](../../../Docs/skills/architecture-boundary.md#구현-전-설계-architect)를 수행한다.

호출자의 사용 방식에서 최소 타입·시그니처와 책임을 도출한다. 기존 구현 재사용을 먼저 검토하고 실제 대안이 있을 때 비교한다. 구조 규칙을 바꾸거나 후보 수를 채우기 위해 새 추상화를 추가하지 않는다.

선택한 경계·소유권·인터페이스, 영향받는 호출자와 테스트, 선택 근거와 검증할 전제를 보고한다. 설계만 요청받았다면 구현하지 않는다. 구현까지 요청된 경우 [품질 게이트](../../../Docs/quality-gates.md)를 완료 조건으로 삼는다.
